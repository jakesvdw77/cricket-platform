### Frontend (`frontend-builder`, after backend types are settled)

1. **`ui/src/api/teamApi.ts`** — add `abbreviation`/`groundName`/`socialLinks: SocialLink[]` to `Team`/`TeamPayload` (mirror `053`'s `leagueApi.ts` extension).
2. **`ui/src/api/teamSquadApi.ts`** — `SquadMember` gains `isCaptain: boolean`; **rename** `updateSquadJerseyNumber`'s payload shape to also send `isCaptain` (the function itself can keep its name/call sites but its request body becomes `{ jerseyNumber, isCaptain }` — every existing caller must be updated to pass the sibling field's current value, per the spec's flagged full-replace trap; consider renaming the function to `updateSquadMember(clubId, teamId, seasonId, playerId, { jerseyNumber, isCaptain })` for clarity at every call site, since "jersey number" alone is no longer an accurate name).
3. **`ui/src/components/TeamForm/`** — add Abbreviation `Input`, Ground `Input`, `SocialLinksFields` block to the existing flat form (no inner Tabs needed — mirror `053`'s exact field-level `LeagueForm` additions, not its Tabs restructuring, since `TeamForm` has no Tabs today and doesn't need them: only 3 new fields, not `LeagueForm`'s five-plus-MediaUpload set).
4. **New `ui/src/pages/manage/TeamCard.tsx`** (or a shared local component both `TeamDirectory.tsx`/`TeamList.tsx` import — decide the exact file location during build, but it must be ONE shared implementation, not two copies, since both files currently duplicate a near-identical `TeamCard` function) — the approved "Detailed" card: avatar+name+abbreviation+section chips, Ground/Captain/Manager/Coach icon rows (each omitted when absent), player/match-count pills, sponsor icons, social icon row. Since this pulls per-team extra queries, batch/fetch per visible team the same "small, bounded, N-requests-is-fine" way this section's existing lists already work — no new backend endpoint (per spec's Non-goals).
5. **`ui/src/pages/manage/TeamDirectory.tsx`** — use the new shared card; add the `?from=` marker is NOT needed here (club-wide origin is the default/no-marker case).
6. **`ui/src/pages/manage/TeamList.tsx`** — use the new shared card; its `viewTo`/`editTo` links gain `?from=section` (read via `useSearchParams` on the destination pages).
7. **`ui/src/pages/manage/TeamDetailPage.tsx`** — full restructure to the "Squad-Focused" bento layout: header chip row (section breadcrumb, ground, captain, player/match counts, active badge) replacing today's "Details" section entirely; Contacts/Sponsors as two-column icon-grid cards using `RecordQuickViewDialog` (`056`, reused unchanged — import from `ui/src/components/RecordQuickViewDialog`); full-width Squad card with richer player tiles (avatar, name, jersey number, captain visually distinguished), Season picker in the card header.
