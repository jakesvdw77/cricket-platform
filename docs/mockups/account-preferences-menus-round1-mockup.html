What would change, per screen

Person screen (today's "Player Hub" chooser): gains Preferences; option B also swaps its top row for a menu.
Player Hub: the Account sub-menu (Invitations, Link requests, Link more players, Switch profile, Back to club, Sign out) goes. One link remains, to the person screen. Switch profile, Back to club and Sign out then live only there.
Preferences (new): per-device switches for now (ticker, menu collapse). Anything else personal can land here later: notification choices, default player, display options.
Not changed: the manager app, the Hub's seven main items, the Hub page header band.
