League page: one place for actions, and an edit mode

Proposal for spec 126. The page follows the standard detail page (Back, page-level actions on the right of the top row, title, key figures, tabs, each tab with its own toolbar line). Page-level actions are few; everything about the schedule lives in the Schedule tab's toolbar; schedule editing becomes a mode of the same page, using the import's row editor, checks and confirmation. Layout rule applied: no control alone in its own row.

A. View mode (Schedule tab), desktop

Top row: Back on the left; Actions menu and the filled Edit league on the right; the Season pill sits beside the title. Schedule toolbar: the scope text on the left; on the right the two switches, then Import schedule (outlined) and Edit schedule (the tab's one filled button). Imports (history) moves into the Actions menu and the Import dialog's own header, so no stray text button remains. Create match is now "Add match" inside Edit schedule.

What this changes, in words

1. The league page top row shrinks from five buttons to three (Actions, Edit league; the Season pill moves beside the title). 2. Every schedule action (Import, Edit, Add) sits in the Schedule tab's toolbar; Teams and Conditions keep theirs. 3. The league edit page loses its Schedule tab (it links to Edit schedule on this page). 4. Edit schedule reuses the import's row editor, validation and Review, so there is one way to change matches in bulk, and import and editing are two entrances to the same checks. 5. Nothing is saved until Review and save.
