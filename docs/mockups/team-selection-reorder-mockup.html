Batting Order: where does Reorder go?

Spec 137 replaces the three small buttons under each column (Select players, Reorder, Announce) with ONE kebab per column, and keeps the quick Announce Team button on a ready column. Reorder is a mode: while a column is being reordered it shows up and down arrows beside each player. Three ways to offer it.

A. Reorder inside the kebab, Done button while editing (the spec default)

Quietest. Reorder is found in the kebab; once started, the column is tinted with arrows and a clear "Done Reordering" button replaces the Announce button until you finish. Per column, so one side can be reordered while the other is left alone, as today.

B. One Reorder toggle chip in the toolbar

One switch for the whole table (like View Entire Season): every column shows arrows at once. Simple to find, but you cannot reorder one side only, and a table-wide mode is easier to leave on by mistake.

C. A visible Reorder text link beside the kebab

Reorder is frequent for a manager, so it stays visible as a text link (like Jump To Today) next to the kebab, and turns into Done while editing. One more control per column than A, but no menu to open.
