Selection analysis

A read-only dialog on the Team Selection hub. One horizontal bar per player shows how many of the games in view they have been picked for, so the manager can see at a glance who plays a lot and who has not played. Mockup only; names and numbers are made up.

1. Where it lives

A quiet Selection Analysis button in the hub toolbar (all four tabs, beside the filters). It opens the dialog below.

2. Desktop dialog

Bars are sorted most picked first. The gold line is the average for the group. Players picked well above it are flagged, and players with no picks are listed last. The hatched part of a bar is 12th man.

Questions for you

  • What counts as "picked": the default shows every selection, drafts included. An Announced Only switch is in the mockup. Say if you would rather drop it.
  • "of 4": the number after each count is the games the player said they were available for, so someone picked 2 of 2 does not look under-used. The alternative is a plain count of all games in view.
  • Juniors: names follow the existing rule (full names inside the manager screens, initials only on anything shared). This dialog is not shared or printed.
  • Share or print: not included. It can be added later if you want to send the breakdown to the selectors.
