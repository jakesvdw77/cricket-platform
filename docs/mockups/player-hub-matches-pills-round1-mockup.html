What I propose

Pills: Live (only when on, with a pulsing dot), Upcoming, Recent, each with its count, using the same pill component as the Stats pages. Default pill: Live if a match is on, else Upcoming, else Recent. Recent: no collapsed panel; a plain list under its pill with the result line coloured by outcome (green win, coral loss, amber tie) and a W/L/T chip, then Show more from the server. Rows: teams, date or countdown, league and venue, plus the chips already there (Selected, availability). Empty pills: a pill with zero hides (Live) or shows a quiet "None yet" (Upcoming, Recent).

Questions: 1) A (pills) or B (stacked)? 2) Should Recent be limited to the last 5 with Show more, or 10? 3) Should the Recent rows show the score, or just the result line?
