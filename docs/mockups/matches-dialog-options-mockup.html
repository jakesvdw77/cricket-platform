Matches dialog: three ways to make it less dull

The dialog today is white with plain bold dates. All three options keep the same content (date and part of day, the match as a link, time, league) and use only the brand green tints already in the app. Option D shows the dialog background as the app's warm cream instead of white, which would apply to every dialog (an old open question).
