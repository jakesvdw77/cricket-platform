Team Sheet, Selected Side (spec 153 draft, mockup)

A third sheet type for the Poster style: Selected Side, beside Blank, One Match and All Matches. It prints only the players picked in Team Selection for the match (no Playing tick box and no order column, the side is chosen: just the names), the Captain line filled from the saved side, C and W/K beside the names, the twelfth man last, and the banner reading PLAYING XI (PLAYING XII with a twelfth man, as shown). Same header, crests, footer, host and sponsors as the Poster.

Order option on the print screen: Batting orderAlphabetical Batting order lists the players in the order set in Team Selection, with the twelfth man last. Alphabetical lists them by surname, twelfth man last. Only the row order changes; no number is printed. Left: batting order. Right: alphabetical. A match with no saved side is skipped in All Matches, and One Match says so with a link to Team Selection.
