League page: one "Manage League" button

Everything you can do to a league lives behind one filled button on the title row. The tab rows carry no buttons. Page header: Back alone; title row = logo, title, badges, Season pill on the left, Manage League on the right.

Desktop, panel open

A popover (not a dialog, so it opens and closes in one click). Grouped by what you are working on, each option with a one-line explanation; the group for the tab you are on is listed first. Menu items keep their icons (the menu exception to the icon rule). Items that need a season are disabled with the reason beneath them.

Notes and decisions this implies

1. Add Match becomes two clicks (Manage League, then Add Match). You said a schedule is mostly set up once, so I think that is fine; the empty Schedule tab also shows its own Import Schedule and Add Match actions. 2. Edit schedule (Phase 2) would be one more item in the Schedule group. 3. This is a pattern, not just a league page: a detail page with many actions gets one Manage button (Manage Team, Manage Season, ...), and Edit stays a menu item. Pages with a single obvious action (list pages: Add X) keep that one button. 4. The tab row can still carry a tab-specific control later if one proves too hidden (for example, Share on Conditions), but the default is no buttons.
