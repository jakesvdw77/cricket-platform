New Group Poll and New Squad Poll, showing the matches first

Today both pages open empty until a section or team is picked. Here they open already showing every upcoming match that has no poll yet, grouped for you. A manager of one section or one team never picks anything: the page is already scoped to theirs. A manager of several sees all of them, one heading each, with the select as an optional filter ("All Sections", "All Teams"). Mockup only, nothing built from this yet.

Fixtures that no group poll covers yet, grouped by section, then by weekend. Soonest first. A group already covered by a poll shows its link instead of a button, so nothing is offered twice.

Rules in this mockup

  • Scope comes from the manager's role: one section or team means no select to use (it shows what they manage, as a quiet filter); several means "All My Sections" or "All My Teams" with a heading per section or team.
  • Only upcoming matches with no poll are offered. Matches already covered are folded into one line with a link to the poll, never a second Create button.
  • The page always lands with something to do, or a plain "Every upcoming match already has a poll" message with a link back to the list.
  • The hub's Section filter still carries across when you arrive from it.
